# basset Homebrew tap

Live, on-demand iOS diagnostics. See [basset.dev](https://basset.dev).

```sh
brew install basset-org/tap/basset
```

Requires macOS 15 or later. Universal binary, Apple silicon and Intel.

`Formula/basset.rb` is generated on every tagged release by
[`release-cli.yml`](https://github.com/basset-org/monorepo/blob/main/.github/workflows/release-cli.yml)
from a template in the monorepo. Edits made here are overwritten by the next release.
